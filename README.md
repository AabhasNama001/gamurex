# 🎮 Gamurex - Gaming Accessories Store

Welcome to **Gamurex**, your go-to destination for premium gaming accessories. Built with cutting-edge frontend technologies and aesthetic UI/UX principles, Gamurex delivers a smooth, immersive shopping experience for gamers.

🌐 **Live Site**: [https://gamurex.netlify.app/](https://gamurex.netlify.app/)

---

## 🛠 Tech Stack

- **Frontend**: React.js
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Framer Motion
- **Routing**: React Router
- **State Management**: useState, useEffect, LocalStorage
- **Assets**: Custom images, videos, and vector art

---

## 💡 Features

### 🏠 Home Page
- Animated landing video banner
- Interactive categories with image previews
- GSAP-powered scrolling transitions

### 🛍️ Products Page
- Dynamic product grid filtered by category
- Animated hover effects and transitions
- "Customize Now" call-to-action section

### 📄 Product Details
- Detailed product view with images and descriptions
- Add to Favorites functionality (saved via localStorage)
- Responsive layout across all devices

### 💖 Favorites Page
- View and manage all your favorited products
- State synced across product listing and detail pages

### 🙋 About Page
- “My Journey” timeline section
- Auto-scrolling testimonial carousel (GSAP)
- Marquee animations and newsletter subscription

### 🔐 Login/Signup Page
- User authentication placeholder (no backend)
- Success toast with delay animation and feedback

### 🧭 Navbar & Footer
- Custom responsive navbar with sidebar for mobile
- Hover animations using SplitType and GSAP
- Footer with newsletter, socials, and quick links
